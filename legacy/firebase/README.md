# Arsip Firebase

Folder ini berisi backend, aturan penyimpanan, dan konfigurasi dari versi Firebase terdahulu. Build aktif menggunakan `backend/` dan tidak men-deploy folder ini. Jangan menjalankan deployment Firebase untuk mengoperasikan aplikasi saat ini.

Dokumentasi lama dipertahankan di `docs/FIREBASE-LEGACY.md` untuk penelusuran migrasi. Kredensial lokal tetap harus disimpan di luar arsip sumber.
